# Mobile

Drive iOS Simulators, Android emulators and real devices with the `agent-device` CLI. Its own skills carry the commands; use them if installed (`ios-simulator`, `android-emulator`, `dogfood`, `agent-device`) instead of guessing flags. Without them, run `agent-device --help`.

1. Build and install the app on the device the user names, or the one already running.
2. Take a snapshot to find elements, then tap, type and scroll through each test.
3. Screenshot each result.
4. Check both platforms when the change is not platform-specific, and a small screen as well as a large one.

Note on each Test plan line whether it ran on an emulator or a real device.
